# WELD brand files

**The mark is the welder's helmet.** A welder's helmet in side view, cream on a
green rounded tile, with a gold lens and a gold pivot where the visor swings.
WELD is the gear you put on to join the parts: put the helmet on, strike the
arc, and the stack holds together. The helmet faces right, toward the work.

The mark was generated with ChatGPT as a single raster image. Every size in this
folder was exported from that one image, so nobody should redraw it — there is no
vector source to redraw from, and the raster is the mark.

No sparks were drawn in the making of this mark; it was generated, not welded.

| Role | Colour |

## Rules
- Never redraw the mark. It is a raster generated with ChatGPT; every size comes
  from the one 1024 image.
- Never recolour it. Green tile, cream helmet, gold lens.
- Never stretch or rotate it. The helmet always faces right.
