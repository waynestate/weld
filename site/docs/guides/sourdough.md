# WELD and Sourdough [#](https://weld.apps.wayne.edu/docs/guides/sourdough.html#weld-and-sourdough)

This page explains how Sourdough and WELD divide the work of starting a Wayne State app, and which one to pick for your project.

## What Sourdough does [#](https://weld.apps.wayne.edu/docs/guides/sourdough.html#what-sourdough-does)

Sourdough is the starter tool for every shape of Wayne State app. It bakes all five: raw PHP, raw PHP with a Vue SPA, Laravel with Blade, Laravel with Blade plus Vue islands, and Laravel with Inertia and Vue.

## Where WELD sits [#](https://weld.apps.wayne.edu/docs/guides/sourdough.html#where-weld-sits)

WELD is one of those shapes, Laravel with Inertia and Vue, with every part already joined and proved to work together. In other words, WELD is the Laravel + Inertia/Vue shape that Sourdough's templates describe, already shaped.

Note

Pick Sourdough when you want a starter you shape yourself. Pick WELD when you want the finished piece.

## Where changes belong [#](https://weld.apps.wayne.edu/docs/guides/sourdough.html#where-changes-belong)

If every app should get a change, it belongs in Sourdough; if only this shape should, it lives here.
