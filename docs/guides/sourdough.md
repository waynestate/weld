# WELD and Sourdough

This page explains how Sourdough and WELD divide the work of starting a Wayne State app, and which one to pick for your project.

## What Sourdough does

Sourdough is the starter tool for every shape of Wayne State app. It bakes four shapes today: raw PHP, Laravel with Blade,
Laravel with Blade plus Vue islands, and Laravel with Inertia and Vue; only raw PHP with a Vue SPA is not available yet.

## Where WELD sits

WELD is one of those shapes, Laravel with Inertia and Vue, with every part already joined and proved to work together.
In other words, WELD is the Laravel + Inertia/Vue shape that Sourdough's templates describe, already shaped.

> [!NOTE]
> Pick Sourdough when you want a starter you shape yourself. Pick WELD when you want the finished piece.

## Where changes belong

If every app should get a change, it belongs in Sourdough; if only this shape should, it lives here.
